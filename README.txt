RAHMAN WIDYANTO — PORTFOLIO WEBSITE

Files:
- index.html — main website
- styles.css — responsive styling
- script.js — project case-study modal interactions
- Rahman-Widyanto-CV.pdf — CV from supplied source
- assets/ — images extracted from the supplied portfolio PowerPoint

HOW TO USE
1. Open index.html in a browser to preview locally.
2. Edit the text in index.html if you want to change content.
3. Replace images inside assets/ if you want different project photos.
4. Upload the whole folder to a static host such as GitHub Pages, Netlify, Vercel, or your own web server.

The site intentionally uses no build step or framework, so it is easy to edit.
